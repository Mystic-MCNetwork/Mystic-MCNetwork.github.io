公告 2026/8/4

我们发现了一个会让部分玩家并无法访问 Mystic Network 的问题。

问题的原因可能是因为域名的 SRV 解析爆炸了，导致 Minecraft 无法正常地解析 Mystic Network 的域名地址。
解决方法就是使用如下的域名加入服务器：

hub.mysticnetwork.top:9178

当然，我们也非常希望能完全解决个别玩家所遇到的 SRV 解析问题。
可如果我们停用了 SRV 解析，会出现两个很明显的问题：

1 - 自动化程序会疯狂地、无差别地扫描暴露在公网的 Minecraft 服务器端口；
2 - 官网的 Web 服务与 Minecraft 服务运行在不同的服务器上。

考虑到遇到 SRV 解析问题的玩家一般为少数群体；
而且如果要停用 SRV 解析的话，我们的官网 Web 服务与 Minecraft 服务将会使用不同的子域名，这显然是一个很麻烦且不必要的做法。
所以为了保证玩家们的体验，我们会继续使用 SRV 解析，感谢各位的理解。

公告 2026/7/31

Mystic Network 已更换了服务器提供商。

对比之前租的 VPS 面板服（4核8G），这次使用的服务器配置（2核4G）比较低。
不仅如此，4GB内存的基础上还要有操作系统的占用，不像面板服一样可以让服务端独享8GB内存。
所以说，这次的体验相对来说会比之前租的面板服差一点，这是无法避免的。
如果大家在游玩过程中遇到了不同步、卡顿、掉线等情况，还请大家耐心一点，这说明服务器真的燃尽了。🙏
当然，如果经费充足的话，我们也很乐意重新订阅来自前服务商的服务器。
只可惜，对于一个完全公益的 Minecraft 服务器来说，这也许会比较困难。从服务器创立三年至今，没有一分钱进入了我们的口袋。
总之，还是感谢大家对 Mystic Network 长久以来的支持！各位的支持就是支撑我们做下去的动力。
